# infra-home

## Setup 

This project leverages [devcontainers](https://containers.dev/) to provide a consistent development environment.
The recommended way to get started is to use the devcontainer CLI.

### Prerequisites

- [Docker](https://www.docker.com/)
- [devcontainer CLI](https://containers.dev/implementors/cli/)

### Getting Started

1. Clone this repository:  
```sh
git clone https://github.com/infra-home.git 
```
2. Run `devcontainer up` to start the development environment
```sh
cd infra-home
devcontainer up
```

Alternatively, you can use the VS Code Dev Containers extension to open this project in a container. 
For more information, see the [VS Code Dev Containers documentation](https://code.visualstudio.com/docs/devcontainers/containers).
